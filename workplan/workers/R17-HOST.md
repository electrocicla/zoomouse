## Security boundaries / owner gates
A UDP bind is an OS-owned local address observation **not** authenticated channel evidence, peer identity, firewall/VPN provenance, OS consent, remote input permission or service. Public/loopback/link-local/wildcard binding is refused. The handle is deliberately inaccessible to Tauri, pairing_tcp and HostAdmission; it cannot accept, send or receive plaintext. Full encrypted M1 requires a reviewed interoperable native TLS1.3/DTLS provider on host and Android, independent pinned host identity, native enrolled phone proof bound to the same protected association and fresh epoch, OS-local interactive consent, firewall/interface provenance, and physical negative A01–A17. This task explicitly does NOT grant any of those.
